
## Run it
Open `res://asset_showcase/asset_showcase.tscn` and press **F6** (Run Current Scene).
Don't use F5: that runs the game's main scene.

## Controls
| Input | Action |
|---|---|
| WASD / arrows (Shift = faster), left-drag, middle-drag | pan |
| Mouse wheel, + / - | zoom |
| Left click a sprite / right click | next / previous animation |
| N / P | next / previous animation on every sprite |
| Space | pause / resume everything |
| R | reset all to default animation |
| 0 / Home | reset camera |
| C | next colour on every diorama creature |
| H | hide help bar |

The blue line under each sprite shows `animation (index/total, frame count)`.
